# Privacy Policy - YUTAKA Tree Manager

**Last updated: July 2026**

## 1. Information We Collect

- **Account details**: Email address, name
- **Location**: Geographic coordinates (with user permission) for weather information
- **Content**: Photos, tree data, treatment logs
- **Usage data**: Login times, in-app actions

## 2. How We Use Information

- Providing the service (tree management, reminders, AI recommendations)
- Improving the app
- Sending alerts and reminders
- Communicating with users (updates, support)

## 3. Information Sharing

We **do not** sell or share personal information with third parties, except:
- Technical service providers (hosting, photo storage) - required for service operation
- AI model (Google Gemini) - for recommendations. Tree data is sent without personally identifiable information
- Legal requirement (court order)

## 4. Storage and Security

- Data is stored on Supabase servers (EU/US)
- Communication is encrypted (HTTPS/TLS)
- Data access is limited to the user themselves (Row Level Security)

## 5. User Rights

- **Access**: Right to request a copy of personal data
- **Deletion**: Right to request account deletion and all associated data
- **Correction**: Right to update incorrect information
- **Portability**: Right to receive data in a common format

## 6. Cookies and Local Storage

The app uses localStorage for:
- Session persistence (login)
- Preferences (language, display)
- Performance caching

## 7. Policy Changes

Material changes will be communicated to users via in-app notification.
